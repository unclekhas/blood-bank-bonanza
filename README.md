# Blood Bank Bonanza 🧛‍♂️

**Blood Bank Bonanza** is a Dracula-themed slot machine game built using **HTML**, **CSS**, and **JavaScript**.

## 🎮 Game Overview

Spin the reels in this creepy, Dracula-inspired slot machine and try your luck at the **Blood Bank Bonanza**! The game features classic slot symbols like vampires, bats, and blood vials. Match symbols to win!

## 🛠️ Technologies Used

- **HTML** for structuring the web page
- **CSS** for styling and layout
- **JavaScript** for interactive functionality

## ⚙️ How to Play

1. Press the **"Spin the Coffin"** button to start the game.
2. The reels will spin, and if you match 3 symbols, you win the jackpot!
3. Get partial matches for smaller rewards!

## 🌐 Live Demo

You can try out the game by downloading the files and running the **index.html** file in any browser.
